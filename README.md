
# Hi there, I'm Will Adams 👋

UK based developer working mainly with **TypeScript**, **React** and
**Astro**. I also go by knife maker, bushcrafter and climber — the knife
making business is what dragged me into web dev in the first place, and
I've been hooked on building things for the web ever since.

🤖 **Currently exploring:** finding my place in the AI world as a developer —
learning agentic workflows with [OpenCode](https://opencode.ai) and
[herdr](https://herdr.dev), and figuring out how best to use (and talk to!)
coding agents.

Always up for interesting opportunities and collaborations — especially
open source, tooling or anything AI-flavoured. The best way to reach me is
[Telegram](https://t.me/bushblade) or [email](mailto:bushblade@gmail.com).
